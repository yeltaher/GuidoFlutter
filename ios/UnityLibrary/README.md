# UnityLibrary (iOS UaaL Target)

This folder hosts the Unity as a Library (UaaL) iOS exported Xcode project (`Unity-iPhone.xcodeproj`), `Data`, and `UnityFramework`.
Generated automatically from Unity Editor using:
- Menu item: `Guido > Export > Export iOS UaaL (Release)`
- CI/CD Batchmode: `Guido.Editor.FlutterUnityExporter.ExportIOSBatchMode`
